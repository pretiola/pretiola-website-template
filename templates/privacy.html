Optional analytics

This starter disables analytics until the site owner configures it. When enabled, Google Analytics loads only after you allow analytics in Privacy choices. You can return to those choices from any footer. Rejecting optional cookies leaves the site usable.

The consent preference lasts up to 180 days. The analytics integration removes query strings and fragments from page addresses and sends only the origin of a referring page. Withdrawing consent clears accessible analytics cookies and reloads the page; it does not delete data already held by a provider.

Advertising features require a separate site setting and a separate visitor choice. Global Privacy Control keeps advertising features off. Describe the providers and data uses you actually enable here before turning them on.
